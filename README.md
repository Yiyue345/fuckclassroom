# 学业助手使用说明

## 安装

请先安装 Python 3.10 或更高版本，然后在项目目录打开 PowerShell：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

## 启动

```powershell
.\.venv\Scripts\python.exe main.py
```

浏览器访问：

```text
http://127.0.0.1:8765
```

如果 `8765` 被 Windows 保留，程序会自动尝试其他端口，请以终端打印的地址为准。也可以手动指定端口：

```powershell
$env:FUCKCLASSROOM_PORT="8766"
.\.venv\Scripts\python.exe main.py
```

## 首次配置与登录

1. 打开左下角的“设置”。
2. 在“账号与网络”中填写统一桂电账号和密码，然后点击“保存更改”。这份账号同时用于课程录播和本科教务。
3. 按需设置默认学期、OCR 引擎、音频预取队列、定时选课间隔和 AI 服务。音频预取队列默认为 3，可在 1 到 8 之间调整。
4. 在侧边栏“通用”分组中打开“账户与认证”。
5. 分别在“课程录播”和“本科教务”区域点击“登录”。两个系统共用账号，但各自保存和显示会话状态。

启动时会尝试复用已保存的会话；会话失效且已保存账号密码时，会尝试自动登录。只有需要图形验证码或其他网页操作时才会打开浏览器窗口；短信动态码会在本地页面弹窗中填写。

登录状态可在左侧栏底部查看。需要重新测试登录时，可在“设置 > 账号与网络”中清除登录状态；此操作会保留自动登录凭据。要同时删除账号密码，请再点击“清除自动登录凭据”。

## 课程录播

1. 使用侧边栏“课程录播”分组进入对应功能。
2. 打开“我的课程”，选择学期或输入课程名称筛选。
3. 点击课程右侧的“打开课程”。进入课程页时会自动同步资源，也可以点击“刷新资源”手动更新。
4. 在课次列表中点击回放链接观看录像；点击“PPT”或“转写”下载对应文件。

文件已经下载时会直接使用本地文件，不会重复下载。打开“文件管理”可以搜索文件、使用系统默认应用直接打开原文件、在文件夹中定位文件或删除文件，并查看格式化后的文件大小。

## 文字提取与 AI 总结

1. 在“设置 > 文字提取”中选择 OCR 引擎。通常使用 `auto`；也可以指定 `rapidocr`、`tesseract` 或 `ai`。
2. 图片型 PPT 推荐使用 `rapidocr`。如选择 `tesseract`，需要先在系统中安装 Tesseract；如选择 `ai`，需要先配置支持图片输入的 AI 服务。
3. 在课程资源页找到课次，点击“提取文字”。程序会优先复用已经下载的 PPT，并合并课件 OCR 与平台转写。
4. 当前页面会显示处理进度，也可以在“提取与总结”中查看所有任务。
5. 点击课次右侧的结果按钮，查看“课件 OCR”“平台转写”和“合并文本”。
6. 在结果页点击“生成 AI 总结”即可生成课程总结。

使用 AI 总结前，请在“设置 > AI 服务”中填写兼容 OpenAI Chat Completions 的服务地址、模型和 API Key。需要在提取完成后直接查看结果时，启用“提取完成后自动打开结果页”。

## 本科教务选课

1. 使用侧边栏“本科选课”分组进入对应功能。
2. 在“选课中心”顶部选择选课批次，然后点击“切换/刷新”。页面会显示该批次的开始时间、结束时间和开放状态。
3. 使用分类标签查看培养方案、可选课程和已选课程。培养方案会按必修、实践、专业限选、专业任选和通识分类展示，同名课程的不同教学班会折叠在同一项下。
4. 展开课程后可查看教师、上课时间和已选/最大人数。
5. 点击“选课”或“退课”直接提交操作，平台返回信息会显示在当前页面右下角。
6. 启用“刷新人数”开关后，页面会定时更新课程容量。

登录成功后会自动刷新选课批次。若页面提示选课入口或会话失效，请先到“账户与认证”验证本科教务会话；自动登录无法完成时再点击“登录”。

## 全校开课

1. 在本科选课侧栏打开“全校开课”。
2. 可按学期、课程名称、教学班、教师、院系和校区筛选。
3. 展开“更多筛选”后，还可使用课程代码、课程类别、修读类型、考核方式、年级、星期、节次、教室、学分、教学周和已选人数等条件。
4. 点击“查询”读取结果，点击右上角“刷新”重新获取全校开课数据。
5. 加入定时选课队列前，先在页面右上角选择该任务使用的选课批次；尚未开放时可选择“等待新批次自动匹配”。
6. 对允许操作的教学班，可直接选课、退课或加入定时选课队列。

需要长期关注指定教学班时，可在“设置 > 定时选课”的“目标教学班名称”中每行填写一个名称。保存后回到全校开课，启用“匹配目标”即可只查看匹配项。

## 定时选课与候补

1. 在“选课中心”或“全校开课”中找到教学班并加入队列；从全校开课加入时需先明确选择选课批次。
2. 任务会等待批次开始，再按设置的间隔提交选课请求。
3. 满课任务会定时检查人数，出现空位后自动尝试选课。
4. 打开“定时选课”可查看任务状态、尝试次数、人数监测结果和平台返回信息，也可以取消、重试或删除任务。

普通失败、会话恢复和满课人数监测的间隔可在“设置 > 定时选课”中分别配置。队列运行期间会话失效时，程序会使用已保存的凭据尝试恢复；需要短信动态码时仍需在本地弹窗中完成验证。

## 校外访问与 Hy2

本科教务登录会根据当前网络选择可用入口。校内可直接访问；校外可使用 WebVPN，也可以在“设置 > 账号与网络”中启用 Hy2。

首次使用内置 Hy2 前，需要安装 Rust 工具链，然后点击“构建内置组件”。构建成功后保持“启用 Hy2 教务代理”打开即可。未启用或启动失败时，系统会继续尝试其他可用入口。

## 缓存与本地文件

- “设置 > 缓存与存储 > 清除缓存”用于刷新课程名、资源链接和选课数据，不会删除登录状态或已下载文件。
- “文件管理”用于查看、直接打开、在文件夹中定位或删除下载的 PPT、平台转写等文件。
- 清除登录状态、清除自动登录凭据和清除缓存是三个独立操作，可按需使用。
