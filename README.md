# 学业助手使用说明

FuckClassroom 是一个面向桂电课程录播、本科教务与选课场景的本地 Web 工具。当前支持课程/直播资源查看、PPT 阅读、本地语音转写、PPT OCR、AI 总结、选课查询与定时选课等功能。

## 安装

请先安装 Python 3.10 或更高版本，然后在项目目录打开 PowerShell。默认安装现在只包含 core 依赖：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

启动后可以直接在“插件管理”页面为需要的插件安装依赖。想一次装齐全部 Python 插件依赖，用：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements/all.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

普通使用不需要安装 Rust 工具链。签到插件会优先使用可选的 wxscan 原生扩展，未安装或编译失败时可回退 OpenCV；Hy2 正常也使用预编译 runner。只有需要编译 wxscan，或 Windows Smart App Control 拦截 Hy2 预编译组件且希望启用本地构建兜底时，才需要额外安装 rustup/Cargo。

## 启动

```powershell
.\.venv\Scripts\python.exe main.py
```

浏览器访问：

```text
http://127.0.0.1:8765
```

如果 `8765` 被 Windows 保留，程序会自动尝试其他端口，请以终端打印的地址为准。也可以手动指定端口：

```powershell
$env:FUCKCLASSROOM_PORT="8766"
.\.venv\Scripts\python.exe main.py
```

## 插件模式

当前 `pluginization` 分支支持按需启用功能插件。默认启动全部功能；也可以通过 `FUCKCLASSROOM_PLUGINS` 只加载需要的 Route、Service 和 Lifecycle：

```powershell
$env:FUCKCLASSROOM_PLUGINS="classroom"
.\.venv\Scripts\python.exe main.py
```

可用内置插件 ID 为 `classroom`、`processing`、`transcription`、`ocr`、`ai_summary`、`attendance` 和 `course_selection`，`core_ui` 始终启用。依赖会自动补齐，例如启用 `transcription` 会自动带上 `processing` 与 `classroom`。应用启动后可访问 `/plugins` 管理页面启停插件、查看运行依赖、安装/修复依赖，并可从本机目录或 ZIP 包添加外部插件；网页配置保存在 `data/plugin_state.json`，启停变更在重启后生效。详细架构见 `docs/plugins.md`。

## 首次配置与登录

1. 打开左下角的“设置”。
2. 在“账号与网络”中填写统一桂电账号和密码，然后点击“保存更改”。这份账号同时用于课程录播和本科教务。
3. 按需设置默认学期、OCR、本地语音识别、音频预取、定时选课和 AI 服务。
4. 在侧边栏“通用”分组中打开“账户与认证”。
5. 分别在“课程录播”和“本科教务”区域点击“登录”。两个系统共用统一桂电账号，但各自保存和显示会话状态。
6. 如果课程还使用课堂派，请在同一页面的“课堂派”区域用课堂派自己的账号密码或手机验证码单独登录；课堂派凭据与学校账号分开加密保存。

启动时会尝试复用已保存的会话；会话失效且已保存账号密码时，会尝试自动登录。只有需要图形验证码或其他网页操作时才会打开浏览器窗口；短信动态码会在本地页面弹窗中填写。

登录状态可在左侧栏底部查看。需要重新测试登录时，可在“设置 > 账号与网络”中清除登录状态；此操作会保留自动登录凭据。要同时删除账号密码，请再点击“清除自动登录凭据”。

## 课程录播、直播与 PPT

1. 使用侧边栏“课程录播”进入“我的课程”。
2. 页面会刷新学期列表并自动选择当前学期，也可以手动切换学期或查看全部课程。
3. 点击课程右侧的“打开课程”进入课程详情页。进入页面时会同步课次与资源，也可以点击“刷新资源”手动更新。
4. 点击任意课次后，上方的课堂画面和 PPT 会一起切换：
   - 直播课次直接播放 HLS 直播流，并持续获取教师推送的实时 PPT。
   - 已结束课次播放课堂录像，并读取录播阶段的完整 PPT 导出。
5. PPT 可以在页面内翻页、全屏查看，也可以下载原始 `.pptx` 文件；录像仍保留“新窗口打开”作为备用入口。

直播期间得到的 PPT 只作为临时内容。课次结束并生成录播后，程序会重新确认课次状态并刷新为完整 PPT，避免长期复用直播阶段的不完整课件。

已下载文件会优先复用；打开“文件管理”可以搜索文件、使用系统默认应用打开原文件、在文件夹中定位文件或删除文件，并查看格式化后的文件大小。

直播课件出现新页面时，程序会自动识别其中的畅课或课堂派二维码。畅课二维码包含有效的 `rollcallId` 和动态数据时，程序会复用统一桂电账号的 CAS 会话完成签到；CAS 会话失效时会用已加密保存的统一账号自动恢复。课堂派使用独立登录令牌，登录后会提交二维码中的 `ticketid`、`expire` 和 `sign`。两种平台都会在课程页明确提示签到成功、二维码过期、点名结束、账号未登录或会话失效。程序不会使用共享账号、伪造位置或绕过平台校验。

默认安装使用 OpenCV 识别二维码，无需额外配置。安装了 `rust_module/wxscan_py` 原生扩展时会优先使用 wxscan，所需模型会在首次识别时自动下载；模型或扩展不可用时会自动回退到 OpenCV。

## 文字提取

课程详情页中的“本地转写”或“提取文字”会执行一套本地提取流程，结果保存在对应课次的输出目录中。

### 语音转写

如果课次有课堂录像，程序会优先使用本地 `faster-whisper`，而不是直接依赖平台转写：

- 默认模型：`small`
- 默认设备：CPU
- 默认精度：`int8`
- 默认语言：中文
- 默认启用 batched transcription 和 VAD
- 默认允许 2 个本地 ASR 任务并发
- 录像不会整段保存到本地磁盘

对于较长的远程录像，如果服务器支持 HTTP Range，程序会把音频按约 10 分钟一块进行分段读取，并使用并行解码和预取队列降低等待时间；如果 Range 不可用，会自动回退到整段流式解码。

第一次使用本地转写时会自动下载 faster-whisper 模型到：

```text
data/models/faster-whisper/
```

平台转写现在只作为兜底：没有可用录像，或本地语音识别失败时，才会尝试使用平台提供的转写文件；内容过短或只有课程元信息的低质量转写会被拒绝。

更详细的本地转写说明见 `docs/local-transcription.md`。

### PPT 文本与 OCR

PPT 文字提取会同时处理：

- PPTX 中可以直接读取的文本框内容；
- 课件中的图片内容；
- 图片型 PPT 的 OCR 结果。

默认 `auto` 模式会优先使用 `rapidocr-onnxruntime`。当前默认配置为 4 个 OCR Worker、每个 ONNX 推理 1 个线程、最大边长 1600，并开启 OCR 结果缓存。

程序还会对 PPT 图片进行去重和有效性筛选，减少重复页、缩略图或低信息图片带来的无效 OCR。

可选 OCR 引擎：

- `auto`：优先 RapidOCR，必要时尝试其他可用引擎。
- `rapidocr`：完全本地运行，适合大多数图片型 PPT。
- `tesseract`：需要系统中额外安装 Tesseract。
- `ai`：使用已配置的视觉模型，需要支持图片输入的 AI 服务。

### 输出结果

一次完整提取通常会生成：

```text
transcript.md       语音转写
ppt_ocr.md          PPT 文本与 OCR
combined.md         合并后的课程文本
summary.md          AI 总结（配置 AI 后默认在文字提取结束时自动生成）
```

任务运行时会在课程页显示总体进度和当前子任务进度，也可以在任务页面查看详细日志。启用“提取完成后自动打开结果页”后，任务结束会直接进入结果页面。

## AI 总结

文字提取完成后，程序默认会把视频语音转写与 PPT/OCR 文本合并为 `combined.md`，随后自动发送给 AI 生成 `summary.md`。使用前请在“设置 > AI 服务”中填写兼容 OpenAI Chat Completions 的服务地址、模型和 API Key。

“文字提取完成后自动生成 AI 总结”可以在同一设置页关闭。未配置 API Key、或 AI 请求失败时，本地转写、PPT OCR 与 `combined.md` 仍会保留；课次结果页的“生成 AI 总结”按钮也可以随时手动重新生成。每次重新提取文字都会先使旧总结失效，避免展示与最新转写不一致的历史总结。

## 本科教务选课

1. 使用侧边栏“本科选课”分组进入对应功能。
2. 在“选课中心”顶部选择选课批次，然后点击“切换/刷新”。页面会显示该批次的开始时间、结束时间和开放状态。
3. 使用分类标签查看培养方案、可选课程和已选课程。培养方案会按必修、实践、专业限选、专业任选和通识分类展示，同名课程的不同教学班会折叠在同一项下。
4. 展开课程后可查看教师、上课时间和已选/最大人数。
5. 点击“选课”或“退课”直接提交操作，平台返回信息会显示在当前页面右下角。
6. 启用“刷新人数”开关后，页面会定时更新课程容量。

登录成功后会自动刷新选课批次。若页面提示选课入口或会话失效，请先到“账户与认证”验证本科教务会话；自动登录无法完成时再点击“登录”。

## 全校开课

1. 在本科选课侧栏打开“全校开课”。
2. 可按学期、课程名称、教学班、教师、院系和校区筛选。
3. 展开“更多筛选”后，还可使用课程代码、课程类别、修读类型、考核方式、年级、星期、节次、教室、学分、教学周和已选人数等条件。
4. 点击“查询”读取结果，点击右上角“刷新”重新获取全校开课数据。
5. 加入定时选课队列前，先在页面右上角选择该任务使用的选课批次；尚未开放时可选择“等待新批次自动匹配”。
6. 对允许操作的教学班，可直接选课、退课或加入定时选课队列。

需要长期关注指定教学班时，可在“设置 > 定时选课”的“目标教学班名称”中每行填写一个名称。保存后回到全校开课，启用“匹配目标”即可只查看匹配项。

## 定时选课与候补

1. 在“选课中心”或“全校开课”中找到教学班并加入队列；从全校开课加入时需先明确选择选课批次。
2. 任务会等待批次开始，再按设置的间隔提交选课请求。
3. 满课任务会定时检查人数，出现空位后自动尝试选课。
4. 打开“定时选课”可查看任务状态、尝试次数、人数监测结果和平台返回信息，也可以取消、重试或删除任务。

普通失败、会话恢复和满课人数监测的间隔可在“设置 > 定时选课”中分别配置。队列运行期间会话失效时，程序会使用已保存的凭据尝试恢复；需要短信动态码时仍需在本地弹窗中完成验证。

## 校外访问与 Hy2

本科教务登录会根据当前网络选择可用入口。校内可直接访问；校外可使用公网入口、WebVPN，也可以在“设置 > 账号与网络”中启用 Hy2。

Hy2 采用两级启动策略：

1. **默认使用预编译 runner**：程序根据当前平台选择仓库中的 CI 预编译组件，并先校验源码指纹与 SHA-256。正常情况下不需要 Rust/Cargo。
2. **Windows 本地构建兜底**：如果 Windows Smart App Control 以 WinError/os error 4551 拦截预编译的 `hy2_serve.exe`，程序会自动尝试使用本机 Cargo 重新编译一次并重试。项目内的 `rust-toolchain.toml` 已固定 Rust 1.96.0。

因此，只有遇到 Smart App Control 拦截并希望继续使用 Hy2 时，才需要准备 rustup/Cargo。可先安装 rustup，然后确认 1.96.0 工具链可用：

```powershell
rustup toolchain install 1.96.0 --profile minimal
cd rust_module\hy2_proxy
cargo --version
```

这里应看到 Cargo 1.96.x。之后重新触发 Hy2，程序会自动走本地构建兜底，不需要手工执行 `cargo build`。

如果本机没有 Cargo，本地兜底会给出明确提示；如果 Smart App Control 连本地构建出的 runner 也继续拦截，程序不会关闭或绕过 Windows 安全功能，此时请关闭 Hy2，继续使用公网教务或 WebVPN。

更详细的工作方式和排错说明见 `docs/hy2.md`。

## 缓存与本地文件

- “设置 > 缓存与存储 > 清除缓存”用于刷新课程名、资源链接和选课数据，不会删除登录状态或已下载文件。
- PPT 缓存会区分直播临时版本和录播最终版本，课次结束后会重新校验并按需刷新。
- 文字提取结果保存在 `data/outputs/`，原始下载文件保存在 `data/downloads/`。
- “文件管理”用于查看、直接打开、在文件夹中定位或删除下载文件。
- 清除登录状态、清除自动登录凭据和清除缓存是三个独立操作，可按需使用。
