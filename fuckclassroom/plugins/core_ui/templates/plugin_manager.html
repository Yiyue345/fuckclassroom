外部插件包格式

查看 plugin.json 的最小示例与兼容性字段。

 
{
  "id": "my_plugin",
  "name": "示例插件",
  "version": "0.1.0",
  "api_version": {{ plugin_api_version }},
  "app_requires": ">=0.1,<0.2",
  "description": "插件说明",
  "requires": ["classroom"],
  "python_requires": ["httpx>=0.27"],
  "entry": "plugin.py"
}

plugin.py 中的 PluginSpec.api_version 必须与清单一致。API 主版本不匹配，或当前 FuckClassroom 版本不满足 app_requires 时，插件仍可保留在插件目录中，但不会被启用或执行。
