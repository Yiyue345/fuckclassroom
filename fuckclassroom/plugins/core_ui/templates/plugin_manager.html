外部插件包格式

最小插件包可以只包含 plugin.json 与 plugin.py。依赖必须写在清单中，并与 PluginSpec.requires 保持一致。

{
  "id": "my_plugin",
  "name": "示例插件",
  "version": "0.1.0",
  "description": "插件说明",
  "requires": ["classroom"],
  "entry": "plugin.py"
}
